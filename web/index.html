MIDTERM CAPSTONE

About this project

Payments Guidelines Query Expert helps payments product, operations and compliance teams find and understand documented requirements. Initial corpus: NPCI circulars.

Loading collection details…

What you can do

Ask a question with citations, inspect the supporting source, and summarise or compare selected circulars. The app runs locally with pretrained models.

How an answer is produced

Your question and filters select relevant passages using keyword and semantic search. A local reranker orders candidates for focused questions. The language model receives a limited selection of evidence and drafts a cited answer. Citation and support checks run before the answer is displayed.

What needs review

The collection is a snapshot, not a live feed. Extracted text and dates can be incomplete. Related circulars do not automatically replace one another. Automated checks help find errors but do not guarantee correctness.

Next steps

1. Validate answers with independent reviewers.
2. Improve retrieval and source quality based on observed failures.
3. Test with payments users and prepare a repeatable local demonstration. Further source coverage is an optional extension after validation.
