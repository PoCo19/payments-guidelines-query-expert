Sub: Migration of “RGCS" system to "Bharat Clearing & Settlement (BCS- IMPS)"
System
Presently, all IMPS member banks are accessing Rupay Global Clearing System (RGCS) for
IMPs related Operational activities (viz. clearing & settlement, dispute management,
downloading settlement and raw files, GsT Reports etc.).
We are pleased to inform that NPCl will be migrating from RGCS to Bharat Clearing &
Settlement (BCS) by October 2018.
After migrating from RGCS to BCS, NPCI will decommission the IMPS - RGCS. Since raw
data and other settlement file formats are same in BCs, there should not be any impact in-·the
reconciliation process.
Key Activities:-
Key activities to be performed by each IMPs member Bank before Go-live (Production Roll
Out) would be:
1. The new BCS-IMPS URL would be hosted using IP 192.168.62.163 port 443. All
Member Banks must whitelist this at their firewall before 1oth Oct 2018, to ensure
issues, the Bank's technical team to co-ordinate with NPCl Operations / Network team
SPOCs & get it resolved.
2. All mermber Bank Admin would be required to login to their new system using the
default password. NPCl shall communicate the default passwords to the user
separately.
3. Upon first login to the IMPs - BCs system, user must set the Secret questions and
change their password immediately.
