In order to achieve below stated objectives and enhance IMPS overall settlement performance, 
NPCI has proposed changes to existing RAW data files structure. These changes were proposed 
and discussed in working group meeting that was conducted on 20th April 2021 & 28th October 
2021 with IMPS member banks. 
Based on bank's feedback on raw data changes, NPCI has decided to Go Live with following 
changes in IMPS RAW data files. 
1.
All the redundant data fields in existing RAW files will be removed. Please refer annexure
- A for fields that will be populated in the New RAW data files
2.
The new RAW data file will have header (date & cycle) & footer (total number of records).
3. The new RAW data files will be in csv format.
The above changes are scheduled to go live with effect from 1 st March, 2022 for banks that 
are ready with these changes at their end. All Banks are required to comply with these 
changes by 30th June, 2022 post which the old RAW data file formats will be discontinued.
