We refer to our earlier circular no. 4 dated 16th April, 2013 on the subject “revised return reason
codes for NACH System.On review of the return reason codes and in consultation with the
participant banks, the return reason codes list is further appended with additional reason codes.
The revised return reason codes is provided in Annexure A.Based on the request of several
memberbanks, we have added a new return reason codeas per the details provided below.
2.Anew code No.68 -A/c Blocked orFrozen has been added to the existing codes.
3. Member banks are requested to ensure that the appropriate return reason codes are used for
returning transactions if any.
