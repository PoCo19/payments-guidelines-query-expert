Migration from XML to text
NACH system has been upgraded recently for better performance in handling 20 mn
transactions in two hours. As a part of the upgrade the core was changed from XML to a text
file processing. As a result of this change the member banks who hitherto were downloading
XML files directly from NACH system are unable to do so. NPCI has been supporting these
banks by providing the XML files based on the requirement of specific banks.
The architecture of NACH system provides for allowing a bank to get the inward and response
files either in the .txt or .xml format. The format chosen by the banks will be applicable for
all the products i.e. ACH - Credit & Debit (306 file format) products for both Inward and
response files. This is a configurable value in the system, currently all the member banks are
configured to receive .txt files only.
The member banks are advised to evaluate both the options and decide on the format in
which they want to receive the inward and response files. The banks that are choosing to
have .xml format should do necessary changes at their end to handle .xml format for inward
and response files for all the products. Note that NPCi will not entertain request for different
format fordifferent products for the same bank.
The member banks that intend to receive .xml file format should send a communication to
ach@npci.org.in to this effect. The banks that are receiving .txt files will continue to do so
by default, there is no requirement for confirmation in case of banks processing .txt files.
The request for .xml confirmation should be sent to us before August 31, 2015. Note that NPCl
shall discontinue the facility of providing off line .xml files w.e.f September 01, 2015.
