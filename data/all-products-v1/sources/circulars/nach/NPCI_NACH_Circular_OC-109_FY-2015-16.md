# Circular No.109 - Increase in Transaction limit for NACH Credit and Debit

Circular/reference number: NPCI/2015-16/NACH/109
Date: 07th October, 2013

<!-- Page 1 -->

NPCI
NATIONALPAYMENTSCORPORATIONOFINDIA
NPCI/2015-16/NACH/109 July14th,2015
To,
All NACHMemberBanks
IncreaseinTransactionlimitfor NACHCreditandDebit
Refer to our Circular No:-18 dated 07th October, 2013 with regards to Increase in Input file size
for APB & EBT Systemand Circular No:-25dated07thOctober,2013regards to Increase in limit
set on NACH Credit (ECS) file size regarding enhancement of maximum file size for APB, EBT and
NACH credit (ECS) to one lakh records. Now that the process has been streamlined and banks are
used to handle large volumes it has been decided to extend the maximum file size of 1 lakh
records per file to all theproducts processed underNACH.
2)Accordingly the inward file size also will be to a maximum of 1 lakh records. All the member
banks are advised to review the process and system and make arrangements accordingly.
3) This is with immediateeffect.
