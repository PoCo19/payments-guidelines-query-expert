# Circular No. 101 - Beneficiary Account Name and Bank Account Number Mandatory in APB File

Circular/reference number: NPCI/2014-15/NACH/CircularNo.101

<!-- Page 1 -->

NPCI
NATIONALPAYMENTSCORPORATIONOFINDIA
NPCI/2014-15/NACH/CircularNo.101 April24,2015
To
AllNACHMemberBanks
Making BeneficiaryAccount Holders Nameand BankAccountNumberMandatoryinAPB
Return File
We refer to our circular number 17 dated October 7, 2013 with reference to making the
beneficiary name and account numbers mandatory in the return file for APB and EBT files.
2.As decided in the last steering committee meeting held on April 15,2015 the
beneficiary name and account number fields would be made mandatory with effect from
June 1, 2015.
3.Beyond the said date,APB return files without the two fields (Beneficiary Name &
accountnumber)will berejectedbyNACH system.
4.Member banks are requested to take a note of the same and ensure that the systems
are put in place to generate the two fields while uploading the return file for all
successfulAPBtransactions.
5.Incaseof any clarificationfeel freetowritetous ach@npci.org.in
Please Note:Member banks who had already implemented and providing the said details,
kindly ignore.
