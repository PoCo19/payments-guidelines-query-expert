Madam/ DearSir,
With reference to our circular No. 83 on the Bank readiness to process new types of transactions,
NPCl proposed to introduce new transaction codes for NACH -Credit -Pungrain related transactions.
2. Currently Member banks are participating in NACH-Credit system (156 characters) are receiving
the Pungrain inward file with the following values and it is similar to NACH -Credit (156 characters).
HeaderCodeCurrentTransactionCode
11 22
3. For better process control we are introducing a new transaction code in the record level only for
Pungrain transactions alone in the NACH Credit (156 characters)format.The new code details are
enclosed below,
Header Code New Transaction Code
11 21
4. All the other fields in the file and the file name will continue to be the same. Please refer to
AnnexureI for the exact file format changes for Pungrain transactions. This will be implemented with
effect from April 15, 2015.All NACH participating banks which are processing the Pungrain
transactions are requested to take note of the same and make the necessary changes at your end.
