Subject: Upgradation of NACH system
Dear Members,
As part of its ongoing commitment fo innovation, security, and operational efficiency, NPCl is pleased
to introduce NACH 3.0 - a significant upgrade to the existing NACH platform. This new version
strengthen data protection, and support higher transaction volumes with greater reliability.
The enhancements outlined below reflect the latest in technology standards and user-centric design,
ensuring that member banks can operate with increased confidence, control, and convenience. These
updates are aimed at streamining processes, enhancing visibility, and reinforcing the overall security
framework of the NACH ecosystem.
Benefits:
Enhanced Gul Interface: Upgraded to align with the latest security standards.
Improved Navigation: Banks can now view all relevant details on a single screen for easier
access and monitoring.
Optimized File Handling: The system can now handte a higher volume of files more efficiently.
Advanced Dashboard: Banks will have access to an enhanced dashboard to track the status
of files presented and received.
Self-Service User Management: Users can create accounts and reset passwords
independenty.
Escalation Matrix Updates: Banks can now submit or update their escalation matrix with NPCl
at their convenience.
Security Enhancements
Advanced security standards have been implemented to strengthen the overall integrity and safety of
the system. These enhancements are designed to align with industry best practices and regulatory
requirements, ensuring secure processing of transactions and mandates.
Key security improvements include:
Advanced technology used for data transmission and storage through both GUl and H2H.
Multi-factor authentication (MFA) for user access (After go live feature will be enabled).
Role-based access controls to ensure appropriate data visibility.
Enhanced audit trails for better traceability and compliance.
Real-time monitoring and alerts for transaction processing and receiving activities.
Disabling of plain text file downloads to prevent unauthorized access to sensitive data.
Implementation of a PGP encryption module for secure file downloads from the front end,
ensuring confidentiality and data integrity.

Training
NPCl has commenced training sessions on the new system, These sessions are designed to help
member banks understand the enhancements and operational changes in the updated platform. Details
regarding the training schedule will be communicated via email as and when sessions are planned. We
encourage all member banks to actively participate in these sessions. Should you require additional
training or support on NACH 3.0, please feel free to reach out to the NPCI team.
To ensure a smooth transition and avoid any impact on the reconciliation process, the file formats for
all settlement reports and adjustments will remain unchanged.
We would like to inform you that the migration of applications to the NACH 3.0 platform is terntatively
scheduied to commence from the first week of July. Detailed information regarding the actual
least 7 days in advance to the migration date. We advise all member banks to stay prepared and
ensure necessary readiness for a smooth transition.
Do and Don't:
Banks are advised to go through the go-live dates and plan accordingly to process files without
pending for the migration planned application.
Ensure to log in to the application and check the navigation for the interface to get familiarized
for easy processing on the day of migration.
Ensure to download the existing system reports and data for reconciliation purposes without
fail. After migration, the old data cannot be retrieved from the new system.
Review the user IDs created for the banks and reconcile based on the user profiles. The
navigation for the GUl screens will differ. For example, maker users will have only maker
options, checkers will have checker options, and administrators will have both facilities.
Avoid requesting a day extension for specific files on the migration day.
Banks are advised to use the proper application for transaction processing. After migration,
transactions should be processed with NACH 3.0, and non-migrated transactions should be
processed with NACH 2.0.
The list of reports that will be generated is given in the section below. Users can use the
appropriate options to download the reports. Reports not listed below will not be available for
bank usage (reports trigger point details provide below in Annexure 1).
if any bank's certificates are expiring on the migration dates mentioned above, plan the change
request with NPCl for updating them prior to the migration dates.
Member banks are advised to take notes of the above and disseminate the instructions contained herein
to all the stakeholders concerned.
