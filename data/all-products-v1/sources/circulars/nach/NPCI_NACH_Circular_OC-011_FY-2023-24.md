Introduction of new product type “KSP” 
Reference may be taken from our circular No: NPCI/2019-20/NACH/Circular No:001 on 
Introduction of new product types in NACH. It has been decided to introduce a new product type 
in NACH to further streamline the processing of PM – Kisan scheme related transactions.  The 
new product code for PM Kisan is “KSP”, technical details are provided in Annexure I.  All the 
member banks(sponsor/destination) banks are advised to take note of the same and do necessary 
changes. Banks should be ready with the said change of the new product types by Jan 5, 2024.  
The next cycle of PM – Kisan, priority payments will be processed with new product code.

Annexure I: 
PM-KISAN PRIORITY 
• 
Product type – “KSP” 
o Applicable for account-based credit only. 
o Input file – Length 262 to 264 at record level. 
o Inward file – Length 266 to 268 at record level. 
 
• 
Product type – “91” 
o Applicable for APB Credit only 
o Input file – Length 01 to 02 at record level. 
o Inward file – Length 01 to 02 at record level. 
 
• 
There is no change in input and response file naming convention, the same process as 
followed by sponsor bank can be continued. 
Inward file naming convention for Inward: 
• 
APB Credit: APB-CR-<bank code>-<date>-TPZKSP<sequence no>-INW.txt 
• 
ACH Credit: ACH-CR-<bank code>-<date>-TPZKSP<sequence no>-INW.txt
