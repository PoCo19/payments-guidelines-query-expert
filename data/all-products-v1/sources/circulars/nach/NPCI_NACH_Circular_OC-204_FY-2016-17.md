# Circular No 204 - Beneficiary name & account number mandatory in APB return file

Circular/reference number: NPCI/2016-17/NACH/CircularNo.204

NPCIL
NATIONALPAYMENTSCORPORATIONOFINDIA
NPCI/2016-17/NACH/CircularNo.204 December14,2016
To,
AllNACHmemberbanks
Beneficiary name & account number mandatory inAPB return file
Refer to NPCI Circular No.185 on "Account Number and Beneficiary Account Holder name
to be mandatorily provided in APB Return File", the beneficiary name & account will be
made mandatory in APB return file w.e.f. January 16, 2017.
After implementation return files uploaded without providing the beneficiary name and
account number for successful transaction the entire file will be rejected, if not corrected
and re-uploaded, all such transactions will be reported as deemed accepted to the various
Government departments.
Member banks should take note of this and make arrangements for the following :
1. Providing account number and name in the return file for all the successful
transactions.
2. The name should be provided as it is updated in the core banking system (CBS).
3. The process should be automated, there should not be any manual intervention.
4. Banks should put in place a monitoring mechanism to check the acknowledgement
files, in case of negative acknowledgment the relevant return file should be
verified, errors corrected and re-uploaded.
5. There should not be any deemed accepted records.
Banks are advised to strictly adhere to the specified timelines.
For any carifications please write back to ach@npci.org.in
