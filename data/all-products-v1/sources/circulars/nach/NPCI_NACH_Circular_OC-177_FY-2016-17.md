# Circular No.177 Removal of Reason Code 03 in APB

Circular/reference number: NPCI/2016-17/NACH/CircularNo.177

<!-- Page 1 -->

NPCI
NATIONALPAYMENTSCORPORATIONOFINDIA
NPCI/2016-17/NACH/CircularNo.177 July 28, 2016
To
AllNACHmemberbanks
Removalofreasoncode"o3"inAPB
Refer to the Circular No.172on the "Changes in return reason for APB"dated July 152016.
On further analysis it is observed that banks are incorrectly mapping the reason “Account
description does not tally" (Reason code: O3).The beneficiary name is optional and the
sponsor banks are not expected to incorporate the name in the input file. It is learnt that a
few banks are mapping the returns on account of“Aadhaar not mapped to the account
number'to"Account description does not tally".
As this reason is not required for Aadhaar based transacstions it has been decided to remove
APB, W.e.f.September O1,2016.Updated list of APBreturnreasoncodes enclosed in the
Annexure I.
All member banks are advised to take note and do necessary modifications at their end for
proper mapping of return reasons and reconcile the Aadhaar numbers in CBS with NPCI
mapper onan ongoing basis.
rejected by NACH.
For any clarifications please write back toach@npci.org.in
