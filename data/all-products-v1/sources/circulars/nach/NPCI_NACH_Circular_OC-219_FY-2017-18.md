RBI mandated NPCI to migrate all transactions from ECS to NACH. In the process, NPCI
migrated all the transactions based on "as is where is basis" for credit and debit. The
migration of credit from EcS (156 file format) to ACH (306 file format) has been completed.
Similarly for the debit transactions from NACH Debit (156 file format) to ACH Debit (306 file
format) scheduled. The detailed road map for the migration is given below
