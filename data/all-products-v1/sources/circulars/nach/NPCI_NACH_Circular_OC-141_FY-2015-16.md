NACH-New mandate format
2015 and Circular No 131 dated September 19, 2015 on revised mandate format. As
per the circulars referred above the sponsor banks were to take all the necessary
stepsfor implementingthenewmandateformat.
Now it has been decided that all the mandates that will be processed from January
16, 2016 should be in the new format only. The destination banks while processing
the mandates should put controls in place to return the mandates in old format. To
facilitate such returns a new return reason is added to the Mms return reason codes.
Sponsor banks also should have control mechanism with Corporates to submit only
new mandates.
“M009-Mandate in old format”
Member banks are requested to take a note of the same and ensure strict compliance.
