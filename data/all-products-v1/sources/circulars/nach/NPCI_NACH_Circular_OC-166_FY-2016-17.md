Warehousing for ACH Credit transactions
It has been decided to provide ware housing facility for ACH credit transactions wherein the
member banks can upload the files 7 working days in advance to the value date. This will
be made available from June 27, 2016 for all account based transactions (ACH credit) which
includes following product types.
a) "LPG"
b) "DBT"
c) “PFM”
(p "ECS"
e) “10 "
Member banks should note that the file should have definite value date for the system to
accept and ware house it. For example if a bank tries to upload same day value date file
post all the ACH credit presentation sessions for the day are completed such files will be
rejected. To re-upload such files the bank has to change the value date in the file to the
futureapplicable date and upload.
On the day of the upload system will do validation of the files uploaded and provide
acknowledgement file immediately.On the value date system will do business validation
one more time, if any of the banks have been removed from clearing or blocked the
transactions drawn on those banks will get rejected. Member banks should put inplace a
process to track the acknowledgement file at the time of upload and also rejects on the
value date.
Note that there is no change in session timings or generation of inward.
