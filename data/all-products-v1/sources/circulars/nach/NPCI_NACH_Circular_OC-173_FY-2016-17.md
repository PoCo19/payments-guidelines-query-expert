Special CharactersinMMsFiles
It is observed that few banks are initiating the MMs files with special characters at the
beginning of the xml file, this in turn getting transmitted in inward files causing issues at
the destination banks leading to unnecessary delay in processing the mandates.
Member banks are advised to strictly follow the MMS file formats as specified by NPCl and
identify the reason for the special character getting populated in the data file. NPCl will
be implementing necessary validations in the system which will identify the file/s
uploaded with special characters at the beginning of the file and reject such files. This
new validation process will be implemented with effect from August 16, 2016.
All the member banks are advised to take note of the same and make necessary changes in
the system so as to generate the data file without special characters to avoid rejections.
Member banks should ensure that the xml tag starts with the open tag (<) symbol only and
does not start with any other special character, including spaces.
