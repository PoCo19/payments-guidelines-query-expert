SubmissionofReturnsFiles
NACH system has been built with the capacityto accept the response files from the destination
banks. The response files can contain both successful as well as returned transactions.While
onboarding thebanks for any product on NACH the response file is also tested therefore all the
participantshasgotthecapacityto submittheresponsefiles.
2. In any financial transaction it is essential that the originating (sponsor bank) gets the
confirmation from the receiving (destination bank)forhaving credited /debited the customerand
the transaction has reached its finality.
3. It is observed that the process of submitting the response file is diligently followed for APB &
EBT products however the memberbanks are not submitting the response files in case of ACH
Debit and ACH Credit transactions which is causing discomfort to the sponsor banks and also
leadingtoacrossthecounterreturns.
4.Banks arerequested to make a noteof the sameand implement the process ofuploading the
returns fileforACHCR/DRandAPB transactionswithoutfail with immediate effect
