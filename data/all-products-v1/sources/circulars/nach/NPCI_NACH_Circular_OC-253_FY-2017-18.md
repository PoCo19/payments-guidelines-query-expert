Penaltyfor representation of debit transactions returnedfor specificreasons
Refer to our circular number 229, on penalty to be imposed for transactions returned with
reasons"No suchaccount"&"Accountclosed".Inthelast NACHsteeringcommitteeheldon
October 04, 2017, it was decided to change the criteria on the following lines;
1.No penalty on returned credit transactions.
2. Penalty is applicable for debit transactions for the following return reasons:
i) NACHDebit(ECS)-“Account closed"and“No suchaccount”
ii) ACHDebit(306)-“Accountclosed"
If any bank continue to present the returned transactions then from third instance of
presentationofsuchreturnedinstrumentswill attractapenaltyofRs.25/-perinstanceof
presentation.
This will beimplemented with retrospective effect i.e.fromSeptember 01,2017.
