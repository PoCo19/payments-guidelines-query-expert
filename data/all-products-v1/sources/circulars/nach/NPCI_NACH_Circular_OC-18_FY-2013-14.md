Increase in Input File Size Capacity of APB and EBT System 
 
 
Madam / Dear Sir,  
 
Based on the feedback received from different stakeholders including banks, a need was felt 
to increase the input file size capacity of APB and EBT System from existing 20, 000 records 
per file to 1,00,000 records per file. 
 
2. NPCI has introduced bulk upload facility for APB and EBT System and has increased the input 
file size capacity for the participating banks w.e.f. 26th September, 2013.  
 
3. Banks acting as sponsor banks for APB and EBT transactions and receiving bulk transactions 
from Government Departments and Corporates can now make use of this facility both in APB 
and EBT System. 
 
4. With the introduction of this functionality, input file containing 1,00,000 records will get 
split into 5 files with 20,000 records each at the SFG (Sterling File Gateway). The sponsor bank 
will have to approve each of the split files at SFG (Sterling File Gateway) for them to move to 
the central system. In case any of the split files are rejected at the time of approval by the 
sponsor bank, the system will give separate response files for the remaining files. 
 
5. All APB and EBT System sponsor banks are requested to kindly make a note of the same and 
may start using the bulk upload facility in APB and EBT System.
