Select Cards which in turn reduces the fee per card for the banks.

Customerjourney for redemption of Features on RuPay Select Debit cards
1. The features can be redeemed on the URL- https:/lwww.rupay.co.in/our-cards/rupay-
debit/rupay-select
2. After logging into the tab, cardholder has to sign up with the below details:
a) Customer name
b) Card type
c) Card Name
d) First 6 digits/8 digits and last 4 digits of card number
e) Mobile number
f) E mail ID
g) Location
h) Password
3. Once the password is created, cardholder can login with the registered E-mail ID &
Password and explore the complementary benefits
4. Post selecting the benefit, customer has to make a Re.1 transaction using the RuPay Select
Debit card to get the booking done.
5. The coupon details will be shared on the registered e-mail ID within 24-48 hours of
transaction.
