Sub: Upgradation of iRGCS back-office system from “iRGCS” to “iRGCS 2.0”  
Please refer to our Operating Circular NPCI/2024-25/RuPay/023 dated 7th January 2025 on 
upgradation of iRGCS operational activities from iRGCS to the new system iRGCS 2.0. 
All the members of RuPay are currently accessing the iRGCS application throughout the day for iRGCS 
related operational activities (Clearing and Settlement, Dispute Management, Downloading Settlement 
Files/Reports, Uploading Clearing Files, Raising Disputes, GST Reports, Invoices, etc.). 
To further enhance the efficiency in iRGCS Operations, we are pleased to inform you that NPCI will be 
upgrading its back-office application from iRGCS to iRGCS 2.0 w.e.f 8th March 2025. The current iRGCS 
application will be decommissioned post the upgradation. 
 
Benefits of the new iRGCS 2.0 system: 
1. The new application will allow users to stage files 24/7 (Dispute bulk upload) as opposed to the 
current system which has a cut off time for file upload and doesn’t allow to Approve Dispute 
during settlement processing time 
2. Enhanced control at bank’s end with the introduction of Bank admin checker user. 
3. Continuous feed of transaction data from Online to back-office system to avoid lead times on cut-
offs and end of day traffic. 
4. Comparatively, the new application has compatibility for a faster generation of reports along-with 
Raw data files. 
5.  Simpler and similar user interface/ experience across all product back-office (settlement) 
platforms. 
6. Enhanced security. 
 
Additionally, following changes have been implemented in the new application: 
 
1. Cycle closure timing has been updated from 11 pm to 8 am for Auth & Disputes. 
 
2. ATM acquired transactions for Mauritius in the SMS format (which are converted to DMS by the 
iRGCS system) will be shown as DMS in the Raw file and in the DSR of both acquirer & issuers. 
Those transactions will continue to be Auto presented. 
3. 87 & 88 auth files would be additionally generated for all transactions.

Annexure-1 
 
Implementation Approach: 
 
1) Currently in production, all member banks are connected to the existing iRGCS system. 
2) As part of the planned upgradation, NPCI will migrate all the existing transaction & dispute details 
from the existing to new database. 
3) Parallel run testing in NPCI Pre-production environment – Both the existing & new Back-office 
systems were connected to the online system as part of the “Parallel run” process. Daily 
settlements were run on both the systems & all generated reports were compared for exact match.  
4) Members could connect to the new iRGCS 2.0 system using the same URL of iRGCS. 
5) Admin Checker user has been introduced in the new iRGCS 2.0 in order to enhance security. 
6) All member bank admins would then be required to login to their new system using the provided 
default password. 
7) Each of the member bank admin user to map the respective Profile & Permissions to the Maker & 
Checker users to perform their daily operations. 
8) Member banks can raise queries through CRM portal via the new category IRGCS Migration March 
2025 added under Rupay International, if any. 
 
 
Critical Timelines for Cutover 
 
1. 28th Feb 2025: 
• 
Member Bank Administrators to ensure that no Onboarding, BIN addition / modification 
/ deletion, BIN / Bank migration is carried out until the iRGCS 2.0 Upgradation. 
2. 8th March 2025, 7 am: 
• 
iRGCS application will be decommissioned, and member banks will not have access to the 
portal. 
3. 8th March 2025, 7 am to 3 pm: 
• 
Migration activities would be carried out between 8th March 7:00 to 15:00 hours. During 
this period all transactions / auth would continue to be pushed to the iRGCS 2.0 system. 
During this time the URL will be down, i.e., banks won’t be able to upload disputes during 
these 8 hours period.  
• 
All the settlement reports of 7th March 2025 & there upon would be available in the new 
portal. 
4. 8th March 2025, 3 pm 
• 
iRGCS 2.0 application will be accessible through the same existing portal.

Annexure-2 
 
Key Responsibilities: 
 
NPCI: 
 
As part of the iRGCS upgradation, NPCI will: 
 
Identify and Nominate Production, Operations & Technology Project Managers to work closely 
with Banks to sort out all Daily activities w.r.t Clearing & Settlement and Dispute Management 
System, provide technical support and provide post go live support for a smooth transition. 
 
Participating Member Banks and Networks: 
 
All members are required to: 
 
1. Identify resources who will be closely working with NPCI, to help upgrade the banks facility to the 
New Clearing & Settlement system, provide post go live support by monitoring and reporting any 
issue to NPCI for resolution. 
2. Banks shall use the same existing URL to access the new application. In case of any connectivity 
issues, the Bank’s technical team to co-ordinate with NPCI Operations/ Network team SPOCs & 
get it resolved. 
3. The password would be set to “Admin@12345” for all the existing Member bank Admins, Maker 
& Checker users. Upon first time login to the new iRGCS 2.0 system, users must set the Secret 
questions and change their passwords immediately. 
4. Member bank admins then need to set the Profile & Permissions for the Maker & Checker users 
for performing the daily operations. 
5. The iRGCS 2.0 bank training PPT is attached herewith for all member banks to familiarize 
themselves with the application. Upon Go-Live this PPT will be made available in the “Manuals 
and Documents” folder of the new application.

System Requirements: 
 
Member to take note of the System Specification Requirement for iRGCS 2.0. Please refer the below 
specifications for easy reference. 
 
 
Particulars 
Specifications 
RAM 
Minimum 1 GB RAM 
Supported Browser Microsoft Internet Explorer and Chrome version 112 & above 
Screen Resolution 
To make the best use of iRGCS 2.0, we recommend a monitor of 1024x768 pixels 
or higher, and 32-bit color or higher 
JavaScript 
JavaScript is used in iRGCS 2.0 to enhance the user experience and provide 
advanced functionality. iRGCS 2.0 requires Java to be installed and turned on. 
Cookies 
iRGCS 2.0 application requires cookies to be enabled in the browser. 
Pop-up Control 
iRGCS 2.0 uses 'pop-up' windows to display some content. If you are using a 
browser that offers pop-up control or is running an add-on program to control 
pop-ups, you may need to take steps to allow pop-ups for this site.
