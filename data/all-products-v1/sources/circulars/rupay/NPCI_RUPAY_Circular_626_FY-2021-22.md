Subject: Update in CsU Value for resetting offline counter limit in offline retail transactions
1. This is with reference NPCI circular- NPCI/2020-21/RuPay/028, dated 18th August 2020 about
offline Retail Payments is provided as Annexure l.
2. RuPay Contactless, as a product, support offline and online contactless transactions. While online
transactions are completed post issuer's authorization, offline transactions are completed on the
basis of the communication between card and terminal only. Such transactions are not received
by issuer banks till the time acquiring bank presents the transactions to NPCl.
 Prior to August 2o20, RuPay Contactless offline transactions could be done only in transit, but post
3. :ou
thecommunicationfrom RBl,dated 6thAugust2020(communication
DPSS.CO.PD.No.115/02.14.003/2020-21) is provided as Annexure ll, pilot for offline transactions
in retail was permitted and subsequently NPCl issued the circular mentioned in point no.1
4. In compliance to above RBl circular, NPCl allows restricted usage i.e upto 20 continuous offline
retail transactions to be allowed on a RuPay Contactless Card. Aforementioned NPCl circular
(NPCl/2020-21/RuPay/028) mentions about the 20 transaction count as terminal floor limit for
offline retail transactions
5. Offline transactions are stored in the card counter and to reset the limit for offline transactions user
has to perform an online transaction in contact mode in line with aforementioned RBl guidelines.
6. lt has been observed that some member banks are not sending the values (Tag 91, DE 55) in the
desired format for the limit reset to happen, hence it is brought to the notice of all member banks
to process transactions as per details provided in Annexure Ill.
7. Above implementation is mandatory to become the part of pilot for showcasing retail offline
transaction (pilot mentioned in point no 3). Also, RBl has extended the pilot closure date till 31st
July 2o21. Therefore all member banks are requested to implement the same on the highest
priority, within two weeks of the circular date.
8. For ensuring the above implementation for the banks already live, single round of certification with
minimal efforts would be supported by NPCl. All the new onboarding will be as per the latest
Implementation Guidelines.
Request all RuPay Contactless issuing member banks to note and bring the above content to the notice
of relevant staff.
