Timeline for AePS certification of Virtual ID & UID Token 
 
With reference to UIDAI circular number 08 of 2019 (attached as Annexure 1), timeline for 
implementation for Virtual ID (VID) and UID Token has been extended till 30th September, 
2019. In case, banks are not able to migrate by 30th September, 2019, the authentication 
services will be allowed subject to a disincentive of Rs. 50,000/- per day w.e.f. 1st October, 
2019. Further, if banks are not able to migrate to API 2.5 by 30th November, 2019, UIDAI 
shall suspend the license keys for AUTH 2.0 and eKYC 2.1 w.e.f. 1st December, 2019.  
To avoid penalty and suspension of license key by UIDAI, it is hereby requested to all banks 
to certify and migrate into production environment by 20th September, 2019. Any delay in 
implementation of UIDAI API version 2.5 by AUA/KUA which will result in levy of penalty/ 
suspension of license key by UIDAI on non-compliant transactions shall be sole 
responsibility of respective banks and NPCI shall not bear any liability of financial 
disincentives resulting from delay in implementation of API 2.5.
