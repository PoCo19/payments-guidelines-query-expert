Dear Sir/Madam,
Currently, there is no standardized Aadhaar status notification mechanism for Members. To address this,
UiDAi has introduced the Aadhaar Status Notification Framework ("Framework"), enabling real-time updates
to Mermbers from UlDAl via an Authentication Service Agency ("AsA") when an Aadhaar number's status is
modified. As part of a phased rollout, the Framework is currently restricted to notifications for deceased
Aadhaar, utilizing APls to maintain the integrity of Aadhaar status data records.
Action Points for Members
1. APls Involved:
The Framework will be operationalized through the implementation of the following APl interactions:
Subscription APl - Register for the service with UIDAl.
Polling API - Fetch Aadhaar status change records.
UID Status Verification AP1 - Validate Aadhaar status post notification. This API is currently not in
scope as it is yet to be enabled by UIDAl.
2. Implementation Process:
Members need to get the AUA code whitelisted at UIDAI for testing.
Members need to complete testing with NPCI through NPCI's certification zone portal.
Post successful completion of testing, Members need to get AUA code whitelisted at UIDAl for
production.
3. Technical Specifications:
Please refer to the "Aadhaar Status Notification APl Specification" document shared along with this
circular as Annexure A. These specifications have been released by NPCl for implementation of
this Framework. These specifications have been aligned with UlDAl's own specifications.
Members are requested to disseminate the information contained herein within their organization for
implementation. Members are also suggested to comply with UlDAl directions issued from time to time
regarding the timelines for completion of this implementation.
