Timeline for AePS certification of Virtual ID &UID Token
To strengthen privacy and security of Aadhaar number holders, UIDAl had introduced concept
of Virtual ID & UID Token. In line with the changes mandated by UIDAl, updated AePS
specifications for Auth 2.5, ONUS 2.5, OFFUS 2.5, OTP 2.5 & eKYC2.5 has been shared to
AePS member banks on:
SpecificationforService Released on
eKYC Interface Specification 30/05/2018
OTP Interface Specification 30/05/2018
AePS XML H-H Specification 13/06/2018
AePS Interface Specification-ONUS 27/07/2018
AePS Interface Specification-OFFUS 26/10/2018
UIDA/vide circularNo.9of 2018dated29June,2018 has stated that penaltieswill be imposed
on AUAs/KUAs who will continue to use older version of APls after 31st August, 2018. As per
the latest UIDAI Circular No. 16 of 2018, UIDAI has extended the timeline for implementation
of Virtual ID and UID Token till 31st January, 2019. To avoid last moment hassle and any
unwarranted action by UIDAl, it is hereby requested to all AUAs/KUAs to complete the
development and line up for certification pertaining to VID & UID token by 15th December,
2018. Any delay in implementation of UIDAIAPI version 2.5 by AUA/KUA which may result in
levy of penalty by UiDAl on non-complaint transactions shall be sole responsibility of
respective AUA/KUA and NPCl shall not bear any liability of financial disincentives resulting
fromdelayin implementationofAPl2.5.
