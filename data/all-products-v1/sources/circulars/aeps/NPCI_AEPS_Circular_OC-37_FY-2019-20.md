UIDAl has introduced Tokenization service for generating UID token for bank customer, the
API for which has been released by NPCl in August, 2018.
Tokenization service is part of authentication transaction; hence Tokenization service will be
charged as per below table
Transaction type Transaction code Transaction Description Switching Fee
AePS ONUSIAuth 16 Tokenization
Please note that switching fee will be charged for successful transactions only.
In line with our constant efforts to introduce new services as per the requirements of our
member entities, NPC has introduced Aadhaar Seeding Status service which can be utilized
by bank in assisted and non-assisted model to facilitate latest Aadhaar Seeding status to any
Aadhaar holder upon his/her request. The API has been released by NPCl in January, 2019.
