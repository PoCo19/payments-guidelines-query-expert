# AePS | OC 69| FY 22 23 | Migration from ISO to XML messaging specification for supporting FMR+FIR authentication

Date: 20th May, 2022

NPCL

To,
All Members of Aadhaar Enabled Payment System (AePS)
Subject:Migration fromIso to XMLmessaging specification for supporting FMR+FIR
authentication
DearSir/Madam,
This is with reference to the circular number NPCl/AePS/2022-23/068 dated 4th May, 2022
advising all AePs members of the extension of the timelines to implement the changes for
migration from ISO-8583 platform to XML platform before 30th August 2022. It was also
informed to members that post the given timeline, the isO8583 platform would be sunset.
We calt attention to the UIDAI (Auth-l) letter No. 11020/198/2017-UIDAl (Auth-l)/1 dated 4th
May, 2022 on the subject ‘FIR-FMR Single PID Block implementation in Aadhaar based
biometric authentication'. UIDAl vide this letter have informed that except for BFD, only FMR
authentication transactions will not be permitted after 3oth June 2022.
In the context of above UIDAi letter, we wish to reiterate to the members that the FIR,
FIR+FMR authentication modalities are supported only in XML specifications. Given the
criticality of this implementation and timelines prescribed by UiDAl, members are advised to
migrate to XML messaging specification latest by 30th June 2022.
From 1st July, onwards transactions of members not supporting FMR+FiR i.e. on XML
All Members are requested to take note of the above and disseminate the information
contained herein to the officials concemed.
