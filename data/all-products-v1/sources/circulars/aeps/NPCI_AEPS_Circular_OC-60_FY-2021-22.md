on ISO 8583 platform to relay messages between participating banks through the NPCl
AePs switch. With the ever-increasing demand for a secure and stable digital payments
platform in the current situation, there is a need for making the AePs platform more
scalable and future-ready.
To realize this vision, it is imperative to migrate to the next generation AePs platform
which is more versatile with customizable API based XML messaging. This will help in
enabling new features and allow faster modifications to meet the ecosystem's
requirements. This new XML platform will allow for more data carrying capacity to facilitate
FiR transactions and also support new use cases. It will also allow Banks to have a
common code for multiple NPCl platforms, enabling optimization of resources and making
the ecosystem future-ready through APl based solutions. XML platform will aiso provide
flexibility to add digital signatures, which will allow members & NPCl to be compliant as
per the IT Act.
All AePs member banks and ecosystem partners will need to migrate their systems to the
new XML. messaging specifications. The core functionality will remain the same except for
the following additions. Additional functionality wil be introduced from time to time, based
on industry requirements. The IsO8583 messaging will be sunset after the migration.
a. Implementation of Finger Image Record (FiR) on financial off-us transactions which
would detect liveliness in all authentication request
b. Self-Help-Group (SHG) transactions will support dual authentication.
Given the said changes, NPCl will sunset all AePS services on ISO-8583 message format
by 30th April 2022. All member banks are requested to impiement the change from Is0-
8583 platform to XML platform before 3oth April 2022 as per the specifications documents
