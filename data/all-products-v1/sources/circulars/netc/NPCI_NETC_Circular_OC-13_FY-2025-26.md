 
E-library. 
 
View and Add/Edit escalation matrix. 
3. Functionality 
PGP tool and keys revision:  
In compliance with the security guidelines, NPCI has strengthened the encryption/decryption 
mechanism used for encryption/decryption of the Reports and dispute files, accordingly the tool 
along with the keys used by the members have been revised and the new revised tool & key shall 
be made readily available to NRCS members from the NRCS back-office. Members to note that 
the files available in the NRCS portal prior to the implementation of the revised files can be 
decrypted using the older tool and keys only. The use of revised tool and key shall be limited to 
the specific participant alone so, the tool cannot be used across multiple participants of the same 
bank. The Keys are embedded within the PGP tool and to use the latest tool.  
Bank user need to navigate to the communications menu option in the NRCS back-office as 
illustrated below and click on Pgp Tool download menu.

Note:  
Each participant must use their own dedicated PGP tool and key pair for all encryption and 
decryption activities going forward. This is a change from the earlier production setup, 
where multiple participants under the same RTGS code could share a common 
encryption/decryption tool and key. For example, entities such as ICICI Acquirer 1, ICICI 
Acquirer 2, ICICI Issuer 1, ICICI Issuer 2, ICICI Govt. Body 1, and ICICI Govt. Body 2 
although all mapped to the same RTGS code were previously permitted to use a single 
common tool and key. 
Post–go-live, this is no longer allowed. All new reports and bulk file encryption/decryption 
must be performed exclusively using the individual PGP tool and key downloaded from 
NRCS for each specific participant. Tools or keys cannot be shared or reused across 
multiple participants under the same RTGS code.

Escalation Matrix:  
To address challenges faced by member banks in collating other members contact details for 
addressing operational queries, NRCS has been enhanced to provide an in-system facility for 
maintaining escalation matrix. Member banks will now be able to add and edit their own 
escalation matrix directly in the NRCS back office. In addition, banks will have the ability to 
view the escalation matrix of other participating members, thereby reducing dependency on 
manual coordination.  
Participant level escalation matrix can be updated by NRCS members by navigating to the 
Add/Edit escalation menu under Communication menu.

Add/Edit Escalation: By using the Add/Edit Escalation menu, the NRCS member can add new

View Escalation: The NRCS member can view the other NRCS members Escalation details by 
navigating the ‘View Escalation’ option.

E-Library  
An E-Library module has been made available in NRCS to serve as a reference point for key 
documents. This module will host procedural guidelines, operating and settlement guidelines, 
operating circulars, product training material and technical specification documents.
