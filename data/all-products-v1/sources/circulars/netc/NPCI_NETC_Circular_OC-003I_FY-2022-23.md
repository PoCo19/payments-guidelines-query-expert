Circular -  Masking of VRN / Tag ID (Monthly Pass Portal) 
 
NETC ecosystem has created provision for the customer to avail Online Monthly Pass via FASTag 
for Toll Plazas. To get the same, customer has to input his/her Tag Id or Vehicle Registration No. 
(VRN) in-order to fetch FASTag details. But as this is a public facing portal, we need to ensure 
protection of consumer’s private information. Hence, NPCI is mandating all NETC members to 
ensure masking of VRN and Tag ID on all public platforms. 
To ensure compliance, all the stakeholder should mask the VRN and Tag ID on all public facing 
platforms as per the below format: 
1. Based on the customer Input, either VRN or Tag ID is required to be masked. i.e. If the 
customer enters VRN as input, then Tag Id will be displayed in masked format and if the 
Tag Id is entered as input, the VRN will be displayed in masked format. 
2. To ensure standardisation, stakeholders must ensure masking is implemented in the 
following format 
a. Tag Id: 3416XXXXXXXXXXXXXXXXC940 (First 4 digits and last 4 digits will be 
visible rest will be masked) 
b. VRN: XXXXXX9762 (Last 4 digits will be visible rest will be masked)  
 
All the NETC stakeholders are to incorporate the changes and implement the same on all public 
facing platforms by 31th August 2022. In case of failure to adhere the timelines, actions would be 
taken as per the NPCI S&E Guidelines.
