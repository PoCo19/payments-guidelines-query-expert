Usinghandhelddevicesforscanningtheinstruments
Member banks have been requesting that the handheld devices be allowed for
scanning the instruments to be presented under CTS. RBl has directed that banks
may, on pilot basis, start using hand held devices subject to the following conditions
1.Truncation should continuetobecarried out within thebank aslaid downin
proceduralguidelines.
2. The scanning can be done from any location across 3 grids.
3.The data presented by the banks should be as per the specifications to enable
NpCl and the destination banks to identify the instruments scanned using
handhelddevices.
4. This is only pilot, based on the results final decision will be taken by RBl.
Technical specifications:Banks should usethe attributefield“SpecialHandling"in
CXF file toprovidean identifierfor instruments scanned using hand held devices.
The field ispart of theexistingfileformat.
1. Currently the banks are using default value 'o', the same can be continued.
2. Banks should provide ‘1' as the value only for the instruments scanned using
handhelddevices.
3. Attribute value presented through CXF will be passed in PXF (inward) file to
thedraweebanktoidentifytheitem.
Member banks participating in pilot are advised to have adequate controls in place
to ensure that only accurate value is captured for instruments scanned using
handheld devices.
