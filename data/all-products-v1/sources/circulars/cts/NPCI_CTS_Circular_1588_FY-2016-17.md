CTSMICRRepairflag:Extensiononremoval ofoldschema
Madam/DearSir,
Refer to our circular No.25 dated March 09, 2016 on the new CHl Specification document
(2.4) for introducing new schema (new schema 010005). The new schema has been
successfully rolled out in all 3 Grids and running concurrently with the old schema (old
schema010003).
Member banks have been advised to implement new schema and start presenting the files
in the new schema. The files presented in the new schema will not have any bearing on
the drawee banks as the inward files don't have any changes.
Note that both the schemas will run concurrently till August 31, 2016. NPCI will withdraw
the old schema with effect from September 01, 2016, post that any file uploaded with old
schemawill berejected.
All the member banks are advised to take a note of the same and ensure compliance.
