Sub: Change in File Format for Late Reversal File (NFS) – Transition from .xlsx to .csv 
Format 
At the request of a large number of member banks it has been decided to provide Late Reversal 
File in .CSV format which is currently shared in .xlsx format.  
 
Effective 17th June 2025, the Late Reversal File will be shared in .csv format as well in addition 
to the existing xlsx format  
 
xlsx Format naming convention: VerifreversalTransXXX03062025_4C_xlsx.pgp 
csv Format naming convention: VerifreversalTransXXX03062025_4C_csv.pgp  
Important Notes: 
• 
Only the file format is being changed – from .xlsx to .csv. 
• 
There is no change in the file content, structure, or encryption methodology. 
• 
Files will continue to be shared through the existing secure channel.  
Migration Timeline: 
• 
Effective Date for .csv Format: 17th June 2025 
• 
Discontinuation of .xlsx Format: 30th September 2025 
  
Post 30th September 2025, the .xlsx format shall be discontinued.  
Member banks are advised to initiate the necessary changes at the earliest and ensure adherence 
to the migration timeline.  The information herein may please be disseminated to all the concerned 
officials.
