Sub:NFSATMNetwork-New reason codeforsuspect fraudtransactionunderDebit adjustment inDMS
As per NFs Operating procedure, acquirer can raise debit adjustment for cash withdrawal transactions, where
cash has been successfully dispensed by the ATMbut it is not settled due to any reason including processing of
fraudulenttransactions.
Acquirers had raised concern that there should be a reason code to indicate that the transaction is purported to
be fraud while raising debit adjustment. The suggestion was approved in the NFS Steering Committee Meeting
(ScM)held on 30th May,2017 for addition of new reason code in DMS for Debit adjustment transactions for
cases wheretheAcquirersuspects thetransactiontobe fraudulent in nature.
We wish to inform that we have made the necessary changes in DMS and the new reason code 'Adjustment
raised for Suspected Fraud'have been made available in DMSwhileraising Debit Adjustment.
Acquirers can select the new reason code'Adjustment raised for Suspected Fraudwhile raising the debit
adjustment, if the acquirer suspects the transaction to be fraud. Acquirers should upload the additional
documents other than the EJ and Switch logs in support of their claim.
Issuing bank while responding to the debit adjustment with the new reason code should take additional
precaution and check the conduct of the account and other details shared by the acquirer.
In case, new reason code is used for a particular transaction while raising debit adjustment, acquirer should also
mark the card as suspect through Frequent Chargeback Query Module (FcQM).This will help in updating the
suspect cardholder repository.
You may please make note of the above and disseminate the information to the officials concerned.
