Sub:AdminUsercreationinNewBack-OfficesystemforNFS
NPCl and its members securely exchange files through NFs back office system (i.e DMS) for reconciliation,
settlement andmanage disputes processing of NFS ATM transactions including Inter-operable CashDeposit (ICD),
DFS,JCBandCUPATMtransactions.
Please be informed that we are in the process of developing an enhanced back office system to manage the
reconciliation, settlement and disputes processing of NFs ATM transactions.The new back-office system Bharat
Clearing and Settlement (BcS), is a web based system that has a Maker & a Checker functionality as one of the
core principles for authorisation of major functionalities. Each NFs member will have 2 Admin users within its
institution, who can further create Maker and Checker role in BCs for their respective users.
Inviewthereof,pleasenoteimportantlythat-
1. The web address of the new back office system, will remain the same as the existing one (DMS). Hence,
no changes are required to be effected by NFS members w.r.t IP whitelisting.NPCI will create 2 Admin
users for each member, so that the Admin users can in turn create subsequent Maker and Checker IDs
withintheirgrouptoperformtheirdaytodayoperational activities.
2.The User ID and Password will be auto-delivered to the respective user's email id, registered during the
AdminusercreationinBCS.
3.The existing back office system -DMS will get discontinued soon after the implementation of new back
office system-BcS.We shall issue a separate Oc intimating the migration date & changes thereon from
DMS to BCS.
We request you to please submit the user details in excel format, preferably senior officials that can act as an
AdminuserinBcS.
